## High-leverage analytic targets

The OpenAI repository documents `OAI.DirichletCharacter.LFunction_ne_zero_of_seven_eighths_lt_re` in [Nonvanishing.lean](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/lean/OAI/NumberTheory/DirichletL/Nonvanishing.lean). It refers to the canonical mathlib L-function with positive modulus and excludes the principal pole. Its comparator permits only the standard three axioms. The proof entry point was located, but it and its dependency chain have **not** been independently checked in this project. Do not import the comparator challenge, which intentionally has an unfinished proof. If the solution is verified, the uniform fixed zero-free half-plane would remove the need for exceptional conductors and near-one zero-density classification in our deterministic transfer; the quantitative log-derivative and Perron estimates would still need proof.

A more direct classical route occurs in [ComplexDensityProof.lean](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/lean/OAI/NumberTheory/Ostmann/ZeroDensity/ComplexDensityProof.lean): `OAI.Ostmann.publishedComplexZeroDensity` is stated for `actualCharacterZeros`, with exponent `3*(1-σ)/(2-σ)` and log power 13. At σ close to one this is bounded by a constant times 1-σ, enough for the power-gap conductor deletion argument (the constants must be rechecked; this is not the identical Montgomery estimate used in the manuscript). The enumeration completeness and multiplicities, family definitions and axiom dependencies need auditing. [LogZeroFree.lean](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/lean/OAI/NumberTheory/Ostmann/Dirichlet/LogZeroFree.lean) states a uniform nonprincipal logarithmic zero-free region; it imports the new Siegel-gap development. [LargeModulusSiegelWalfisz.lean](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/lean/OAI/NumberTheory/Jacobsthal/Sieve/LargeModulusSiegelWalfisz.lean) states an exponential cube-root-log modulus range, insufficient alone for our much larger moduli. None of these density/zero-free/progression statements has yet been independently rebuilt here. The experimental density import [run 45825177325](https://github.com/JoseBrox/Factoring_after_Google/actions/runs/45825177325) found 1,154 reachable local proof modules, 230 mathlib roots, and a further PNT+ digamma-series import. It correctly stopped before compilation because that extra package was not yet pinned. The extraction and adapter experiment is preserved on the [lean-density-reuse branch](https://github.com/JoseBrox/Factoring_after_Google/tree/lean-density-reuse); it is not a certified dependency.

The QRH alternative also suggests replacing the supplied-order splitter's large Burgess package by a deterministic search for a small prime with nontrivial active quadratic character, provided a **uniform** power-saving twisted-prime estimate can be proved from the fixed zero-free region. This is a potential simplification, not a certified new complexity result.

The existing `lean/` proof library remains on its tested toolchain. Modern imports use incompatible versions; a separate proof target avoids invalidating the existing audit. Ultimately a common toolchain and end-to-end composition are required. The widened randomized analytic contracts remain genuine mathematical obligations, not just a library-version issue.
