Updated 26 November 2026. This is an explicit **equal-weight milestone
metric**, not a time estimate, theorem-count percentage, or estimate of
the remaining mathematical difficulty. A milestone counts only once the
stated package has been compiled with warnings as errors and its proof
dependencies checked. A written proof, a conditional theorem whose
intended premises have not been established, or an unfinished
integration does not count as completion of the corresponding endpoint.
The deliberately granular finite packages and larger analytic packages
are not equally costly; the latter dominate the remaining research.
