# Staged proofs and independent checks

BitArithmetic, EulerDecay, LatticeClearing, ModularBits and CharacterMoments have been strictly compiled and individually audited and promoted into the core. The copies here retain their explicit audit roots for CI. See [the receipt](../verification/lean/qrh-continuation.md). DeterminantHeight, ModularPower, BinaryGCD, SaddleCalculus and ReadinessTransfer also passed strict verification and were promoted. See the [aggregate receipt](../verification/lean/reconstruction-readiness.md). RationalRecovery, SaddleDecay, NumberFieldNorm and PrefixBounds have also passed strict compilation and been promoted. See [the new aggregate receipt](../verification/lean/progression-readiness.md). IdealCancellation and PrimitiveFibre also passed strict individual verification and were promoted at 25b4191.

The separate [QRH target](../lean-qrh/) imports the exact modern endpoints. The mathematical [weighted AP proof](../docs/qrh_weighted_progressions.md) and [rough/bad-child continuation](../docs/weighted_rough_bad_child.md) require formalization of their analytic arguments. The [completion register](../docs/lean_completion.md) gives a fixed metric.

The CI workflow independently checks every file against the pinned Lean 4.19 core and records the actual compiler exit code and transitive axiom roots. It rejects any failure, warning, missing report or nonstandard axiom.
