# Exact finite verification

Run every check from the repository root:

```sh
python3 verification/run_all.py
```

Requirements: Python 3.10 or later and Node.js 18 or later. No package installation is needed. The programs use exact integers, rational arithmetic, or exact finite fields. The fixed expected outputs are in [expected_results.json](expected_results.json).

| Program | What it checks | What it does not establish |
|---|---|---|
| `verify_deterministic_parameters.py` | Nineteen affine inequalities for the replacement schedule and a finite-field root-count counterexample | Analytic transfer estimates |
| `verify_enumeration_burgess_audit.py` | Corrected character-sum counterexample, exact Burgess exponent arithmetic, fixed-dimensional enumeration bounds | Every instance of lattice enumeration or the analytic Burgess theorem |
| `verify_recursion_budget.py` | Repaired rational margins, the failed earlier choice, and the cubed recurrence inequality for constant 91.4 | Widened distribution or square-certification contracts |
| `verify_ramification_and_relation.py` | Ramified local Gram decompositions, inert root counts, one-shot and chain counts on small semiprimes | Asymptotic distribution estimates |
| `verify_mixed_prime_chain.py` | Mixed-sign promises with repeated prime factors and exponents divisible only by the required $p-1$; trace-rank counterexample | Construction of promised inputs for arbitrary $N$ |
| `verify_sparse.js` | Small-field sparse projection, binary components, Euler identities, exhaustive hidden-sign uniformity, with fixed seed | A large-input implementation benchmark or analytic runtime theorem |
| `verify_public_implementation.py` | Public ring powers against independent $2\times2$ matrix powers, agreement with retained exact count routines, proper factors, invalid-input guards | An end-to-end general factoring implementation |
| `verify_selected_sections.py` | Selected-value ideals, complete chart-coefficient identities, and an independent geometric-power circuit for small semiprimes | A method for constructing the selected value before factors are known |

All inputs are generated by the scripts. There are no hidden datasets, remote calls, or unrecorded random seeds. The JavaScript seed is recorded in its output. Assertions fail immediately on a discrepancy. The runner then compares complete JSON objects against the committed expected results.

To inspect one check, invoke its file with `python3` or `node`. To reproduce the small public example, run `python3 examples/quadratic_relation_example.py`.

`python3 verification/run_all.py --record` deliberately replaces the expected transcript. Use it only after reviewing an intentional change; normal verification never rewrites the expected values. The source hashes and historical origins of the retained checks are documented in [reproducibility](../docs/reproducibility.md) and [provenance](../provenance/README.md).
